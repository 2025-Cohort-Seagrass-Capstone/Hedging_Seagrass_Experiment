# Seagrass-Stats

Description: Statistical analysis of seagrass data for the Hedging Materials for *Thalassia testudinum* Nursery Establishment and *Halophila stipulacea* Management in the Caribbean experimental project performed in Brewers Bay, USVI at the University of the Virgin Islands.

Collaborators: Savanna R. Saunders and Adam Krogmann

# Folders

## Brewers Plots

[Code:]{.underline} All visual and statistical analysis script files for Brewers plot data

[Figures/Publication_Ready:]{.underline} All generated figures from Brewers plots script files submitted to journal

[DataFiles:]{.underline} All excel files used in scripts for visual and statistical analysis.

## Preliminary_Work

[Water Tables:]{.underline} Script files and data files for analyzing a preliminary study with *Thalassia testudinum* growth in water tables.

[Other files present:]{.underline} These script files and data files were used in preliminary statistical analyses.
